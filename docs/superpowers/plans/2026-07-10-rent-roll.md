# Rent Roll Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only Rent Roll tab on the Property Asset record page: summary KPIs + a sortable, expandable units table, backed by two new Yardi-mirror child objects seeded with dummy data.

**Architecture:** `Unit__c` (master-detail under `Property_Asset__c`) and `Rent_Step__c` (master-detail under `Unit__c`) store what Yardi will send. A cacheable Apex controller (`RentRollController`) returns one DTO (summary + units + nested steps). One LWC (`rentRoll`) renders it, following the repo's computed-inline-style pattern. A new flexipage adds the tab; app-level actionOverrides activate it.

**Tech Stack:** Salesforce metadata API 62.0, Apex, LWC. Spec: `docs/superpowers/specs/2026-07-10-rent-roll-design.md`.

## Global Constraints

- Branch: `feature/rent-roll`. Commit after every task.
- API version **62.0** everywhere (`sfdx-project.json` sourceApiVersion).
- Default org is **DPEG-Acq-3** (`sf config get target-org`). All `sf` commands run from the **repo root** `f:\Acquisition-Design-Salesforce` (a drifted CWD breaks `-d` paths — known gotcha).
- **Deploy order gotcha:** `sf project deploy start` rolls back everything on any failure, and a flexipage referencing an LWC not yet in the org fails with a misleading "couldn't retrieve the design time component information". Always deploy objects/classes/LWCs as their own successful deploy BEFORE any flexipage/app deploy.
- Flexipage XML: each `<itemInstances>` wrapper holds exactly ONE `<componentInstance>`.
- LWC `js-meta.xml`: target `lightning__RecordPage` with **no** `targetConfigs` objects filter (repo gotcha: it rejects `objects=`).
- New fields get NO FLS on deploy — the perm set task is mandatory or SOQL in the org UI shows "No such column".
- Master-detail fields never get `fieldPermissions` entries (they're universally required).
- All new metadata lives under `force-app/main/default/`.

```apex
        System.assertEquals(1000, dto.summary.nnnMonthlyTotal, 'NNN total sums');
        System.assertEquals(2, dto.summary.occupiedCount, 'Occupied count');
        System.assertEquals(1, dto.summary.vacantCount, 'Vacant count');
        System.assertNotEquals(null, dto.summary.lastSynced, 'Last synced derives from units');
```

- [ ] **Step 2: Write the controller**

`RentRollController.cls`:
```apex
/**
 * Backs the rentRoll LWC on the Property Asset record page. Unit__c/Rent_Step__c are a
 * read-only mirror of Yardi (dummy-seeded until the nightly sync exists); this controller
 * only reads and aggregates. All display formatting happens client-side.
 */
public with sharing class RentRollController {

    public class StepDTO {
        @AuraEnabled public Date periodStart;
        @AuraEnabled public Date periodEnd;
        @AuraEnabled public String periodLabel;
        @AuraEnabled public Decimal monthlyRent;
        @AuraEnabled public Decimal rentPsf;
        @AuraEnabled public String stepType;
        @AuraEnabled public String note;
    }

    public class UnitDTO {
        @AuraEnabled public Id unitId;
        @AuraEnabled public String suite;
        @AuraEnabled public String tenant;
        @AuraEnabled public String status;
        @AuraEnabled public Decimal squareFeet;
        @AuraEnabled public Date leaseStart;
        @AuraEnabled public Date leaseEnd;
        @AuraEnabled public Decimal currentRent;
        @AuraEnabled public Decimal currentRentPsf;
        @AuraEnabled public Decimal askingRentPsf;
        @AuraEnabled public Decimal estimatedNnnPsf;
        @AuraEnabled public Decimal nnnTax;
        @AuraEnabled public Decimal nnnInsurance;
        @AuraEnabled public Decimal nnnCam;
        @AuraEnabled public Decimal nnnMonthlyTotal;
        @AuraEnabled public Decimal nnnPsf;
        @AuraEnabled public List<StepDTO> steps = new List<StepDTO>();
    }

    public class SummaryDTO {
        @AuraEnabled public Decimal totalSqFt = 0;
        @AuraEnabled public Decimal occupiedSqFt = 0;
        @AuraEnabled public Decimal vacantSqFt = 0;
        @AuraEnabled public Decimal occupiedPct;
        @AuraEnabled public Decimal vacantPct;
        @AuraEnabled public Decimal monthlyRent = 0;
        @AuraEnabled public Decimal blendedPsf;
        @AuraEnabled public Decimal nnnMonthlyTotal = 0;
        @AuraEnabled public Integer occupiedCount = 0;
        @AuraEnabled public Integer vacantCount = 0;
        @AuraEnabled public Datetime lastSynced;
    }

    public class RentRollDTO {
        @AuraEnabled public SummaryDTO summary = new SummaryDTO();
        @AuraEnabled public List<UnitDTO> units = new List<UnitDTO>();
    }

    @AuraEnabled(cacheable=true)
    public static RentRollDTO getRentRoll(Id propertyAssetId) {
        RentRollDTO dto = new RentRollDTO();
        if (propertyAssetId == null) {
            return dto;
        }

        for (Unit__c u : [
            SELECT Id, Suite_Number__c, Tenant_Name__c, Status__c, Square_Feet__c,
                   Lease_Start__c, Lease_End__c, Current_Monthly_Rent__c, Current_Rent_PSF__c,
                   Asking_Rent_PSF__c, Estimated_NNN_PSF__c, NNN_Property_Tax__c,
                   NNN_Insurance__c, NNN_CAM__c, NNN_Monthly_Total__c, NNN_PSF__c,
                   LastModifiedDate,
                   (SELECT Period_Start__c, Period_End__c, Period_Label__c, Monthly_Rent__c,
                           Rent_PSF__c, Type__c, Note__c
                    FROM Rent_Steps__r
                    ORDER BY Sort_Order__c ASC NULLS LAST)
            FROM Unit__c
            WHERE Property_Asset__c = :propertyAssetId
            ORDER BY Suite_Number__c ASC NULLS LAST
        ]) {
            UnitDTO ud = new UnitDTO();
            ud.unitId = u.Id;
            ud.suite = u.Suite_Number__c;
            ud.tenant = u.Tenant_Name__c;
            ud.status = u.Status__c;
            ud.squareFeet = u.Square_Feet__c;
            ud.leaseStart = u.Lease_Start__c;
            ud.leaseEnd = u.Lease_End__c;
            ud.currentRent = u.Current_Monthly_Rent__c;
            ud.currentRentPsf = u.Current_Rent_PSF__c;
            ud.askingRentPsf = u.Asking_Rent_PSF__c;
            ud.estimatedNnnPsf = u.Estimated_NNN_PSF__c;
            ud.nnnTax = u.NNN_Property_Tax__c;
            ud.nnnInsurance = u.NNN_Insurance__c;
            ud.nnnCam = u.NNN_CAM__c;
            ud.nnnMonthlyTotal = u.NNN_Monthly_Total__c;
            ud.nnnPsf = u.NNN_PSF__c;
            for (Rent_Step__c s : u.Rent_Steps__r) {
                StepDTO sd = new StepDTO();
                sd.periodStart = s.Period_Start__c;
                sd.periodEnd = s.Period_End__c;
                sd.periodLabel = s.Period_Label__c;
                sd.monthlyRent = s.Monthly_Rent__c;
                sd.rentPsf = s.Rent_PSF__c;
                sd.stepType = s.Type__c;
                sd.note = s.Note__c;
                ud.steps.add(sd);
            }
            dto.units.add(ud);

            Decimal sqFt = u.Square_Feet__c == null ? 0 : u.Square_Feet__c;
            dto.summary.totalSqFt += sqFt;
            if (u.Status__c == 'Occupied') {
                dto.summary.occupiedCount++;
                dto.summary.occupiedSqFt += sqFt;
                if (u.Current_Monthly_Rent__c != null) {
                    dto.summary.monthlyRent += u.Current_Monthly_Rent__c;
                }
                if (u.NNN_Monthly_Total__c != null) {
                    dto.summary.nnnMonthlyTotal += u.NNN_Monthly_Total__c;
                }
            } else {
                dto.summary.vacantCount++;
                dto.summary.vacantSqFt += sqFt;
            }
            if (dto.summary.lastSynced == null || u.LastModifiedDate > dto.summary.lastSynced) {
                dto.summary.lastSynced = u.LastModifiedDate;
            }
        }

        if (dto.summary.totalSqFt > 0) {
            dto.summary.occupiedPct = (dto.summary.occupiedSqFt * 100 / dto.summary.totalSqFt).setScale(1);
            dto.summary.vacantPct = (dto.summary.vacantSqFt * 100 / dto.summary.totalSqFt).setScale(1);
        }
        if (dto.summary.occupiedSqFt > 0 && dto.summary.monthlyRent > 0) {
            dto.summary.blendedPsf = (dto.summary.monthlyRent * 12 / dto.summary.occupiedSqFt).setScale(2);
        }
        return dto;
    }
}
```

```js
import { LightningElement, api, wire } from 'lwc';
import getRentRoll from '@salesforce/apex/RentRollController.getRentRoll';

const MS_PER_MONTH = 1000 * 60 * 60 * 24 * 30.44;
const DOT_GREEN = '#1A7A6B';
const DOT_AMBER = '#D4940A';
const DOT_RED = '#C0392B';

const money = (n) =>
    '$' + Number(n).toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
const psf = (n) => '$' + Number(n).toFixed(2);
// Apex Date arrives as 'YYYY-MM-DD'
const mdy = (iso) => {
    if (!iso) return '';
    const p = String(iso).split('-');
    return `${parseInt(p[1], 10)}/${parseInt(p[2], 10)}/${p[0]}`;
};
const dateVal = (iso) => (iso ? new Date(iso + 'T00:00:00') : null);

export default class RentRoll extends LightningElement {
    @api recordId;
    data;
    error;
    expanded = {};
    sortKey = null;
    sortDir = 1;
    tip = null;

    @wire(getRentRoll, { propertyAssetId: '$recordId' })
    wired({ data, error }) {
        if (data) {
            this.data = data;
            this.error = undefined;
        } else if (error) {
            this.error = error;
            this.data = undefined;
        }
    }

    get isLoading() {
        return !this.data && !this.error;
    }
    get errorMessage() {
        const e = this.error;
        return (e && e.body && e.body.message) || 'Unknown error';
    }
    get hasUnits() {
        return !!this.data && this.data.units.length > 0;
    }
    get isEmpty() {
        return !!this.data && this.data.units.length === 0;
    }
    get unitCount() {
        return this.data ? this.data.units.length : 0;
    }

    get summary() {
        const s = this.data.summary;
        return {
            totalSqFt: Number(s.totalSqFt || 0).toLocaleString('en-US'),
            occupiedSqFt: Number(s.occupiedSqFt || 0).toLocaleString('en-US'),
            vacantSqFt: Number(s.vacantSqFt || 0).toLocaleString('en-US'),
            occupiedPct: s.occupiedPct == null ? '' : s.occupiedPct + '%',
            vacantPct: s.vacantPct == null ? '' : s.vacantPct + '%',
            monthlyRent: money(s.monthlyRent || 0),
            occupiedLabel: s.occupiedCount + ' occupied unit' + (s.occupiedCount === 1 ? '' : 's'),
            occBarStyle: 'width:' + (s.occupiedPct || 0) + '%',
            vacBarStyle: 'width:' + (s.vacantPct || 0) + '%',
            lastSynced: s.lastSynced
                ? 'Last synced: ' +
                  new Date(s.lastSynced).toLocaleString('en-US', {
                      month: 'short', day: 'numeric', hour: 'numeric', minute: '2-digit'
                  })
                : 'Not yet synced'
        };
    }

    get headers() {
        const arrow = (k) => (this.sortKey === k ? (this.sortDir === 1 ? ' ▲' : ' ▼') : '');
        return {
            suite: 'Suite #' + arrow('suite'),
            sqft: 'Sq Ft' + arrow('sqft'),
            rent: 'Monthly Rent' + arrow('rent'),
            end: 'Lease Start → End' + arrow('end')
        };
    }

    get totals() {
        const s = this.data.summary;
        return {
            occLabel: s.occupiedCount + ' occupied · ' + s.vacantCount + ' vacant',
            sqftSplit:
                Number(s.occupiedSqFt || 0).toLocaleString('en-US') + ' occ · ' +
                Number(s.vacantSqFt || 0).toLocaleString('en-US') + ' vac',
            blendedPsf: s.blendedPsf == null ? '—' : psf(s.blendedPsf),
            nnnTotal: money(s.nnnMonthlyTotal || 0)
        };
    }

    sortValue(u) {
        const k = this.sortKey;
        if (k === 'suite') return u.suite ? parseInt(u.suite, 10) : Infinity;
        if (k === 'sqft') return u.squareFeet == null ? Infinity : u.squareFeet;
        if (k === 'rent') return u.currentRent == null ? Infinity : u.currentRent;
        if (k === 'end') {
            const d = dateVal(u.leaseEnd);
            return d ? d.getTime() : Infinity;
        }
        return 0;
    }

    get rows() {
        let units = [...this.data.units];
        if (this.sortKey) {
            units.sort((a, b) => {
                const av = this.sortValue(a);
                const bv = this.sortValue(b);
                if (av === bv) return 0;
                if (av === Infinity) return 1;   // nulls/vacant always last
                if (bv === Infinity) return -1;
                return (av - bv) * this.sortDir;
            });
        }
        const today = new Date();
        return units.map((u) => {
            const occupied = u.status === 'Occupied';
            const isExpanded = occupied && !!this.expanded[u.unitId];

            let dot = null;
            const end = dateVal(u.leaseEnd);
            if (occupied && end) {
                const months = (end.getTime() - today.getTime()) / MS_PER_MONTH;
                const color = months > 12 ? DOT_GREEN : months >= 6 ? DOT_AMBER : DOT_RED;
                dot = {
                    style: 'background:' + color,
                    title: 'Lease ends ' + mdy(u.leaseEnd) + ' — about ' +
                        Math.max(0, Math.round(months)) + ' months out'
                };
            }

            let psfDisp = '—';
            let psfClass = 'mono';
            if (u.currentRentPsf != null) {
                psfDisp = psf(u.currentRentPsf);
            } else if (u.askingRentPsf != null) {
                psfDisp = psf(u.askingRentPsf) + ' asking';
                psfClass = 'mono asking';
            }

            const hasNnn = u.nnnMonthlyTotal != null;
            let nnnDisp = '—';
            let nnnClass = 'mono';
            if (hasNnn) {
                nnnDisp = money(u.nnnMonthlyTotal);
                nnnClass = 'mono nnn-val';
            } else if (u.estimatedNnnPsf != null) {
                nnnDisp = psf(u.estimatedNnnPsf) + '/SF est.';
                nnnClass = 'mono nnn-est';
            }

            return {
                id: u.unitId,
                panelKey: u.unitId + '-panel',
                occupied,
                isExpanded,
                rowClass: occupied ? 'occ' : 'vac',
                chevStyle: isExpanded ? 'transform:rotate(180deg)' : '',
                suiteDisp: u.suite || '—',
                tenantDisp: u.tenant || '— Vacant —',
                tenantClass: u.tenant ? 'tenant' : 'tenant vacant',
                sqftDisp: u.squareFeet == null ? '—' : Number(u.squareFeet).toLocaleString('en-US'),
                rentDisp: u.currentRent == null ? '—' : money(u.currentRent),
                psfDisp, psfClass,
                termDisp: occupied && u.leaseStart ? mdy(u.leaseStart) + ' → ' + mdy(u.leaseEnd) : '—',
                dot,
                nnnDisp, nnnClass,
                panelTitle: 'Suite ' + (u.suite || '—') + (u.tenant ? ' · ' + u.tenant : ''),
                nnnTaxDisp: u.nnnTax == null ? '—' : money(u.nnnTax),
                nnnInsDisp: u.nnnInsurance == null ? '—' : money(u.nnnInsurance),
                nnnCamDisp: u.nnnCam == null ? '—' : money(u.nnnCam),
                nnnTotDisp: hasNnn ? money(u.nnnMonthlyTotal) : '—',
                nnnPsfDisp: u.nnnPsf == null ? '—' : psf(u.nnnPsf),
                steps: (u.steps || []).map((s, i) => {
                    const start = dateVal(s.periodStart);
                    const stepEnd = dateVal(s.periodEnd);
                    const active = !!(start && stepEnd && today >= start && today <= stepEnd);
                    const noRent = s.monthlyRent == null;
                    return {
                        key: u.unitId + '-s' + i,
                        period: s.periodLabel || mdy(s.periodStart) + ' – ' + mdy(s.periodEnd),
                        active,
                        rowClass: active ? 'srow active' : 'srow',
                        rentDisp: noRent ? (s.note || '—') : money(s.monthlyRent),
                        rentClass: noRent ? 'snote' : active ? 'srent srent-bold' : 'srent',
                        psfDisp: s.rentPsf == null ? '—' : psf(s.rentPsf),
                        typeLabel: s.stepType || '',
                        tagClass: s.stepType === 'Renewal Option' ? 'tag gold' : 'tag navy'
                    };
                })
            };
        });
    }

    toggleRow(event) {
        const id = event.currentTarget.dataset.id;
        const u = this.data.units.find((x) => x.unitId === id);
        if (!u || u.status !== 'Occupied') return;
        this.expanded = { ...this.expanded, [id]: !this.expanded[id] };
    }

    sortBy(event) {
        const key = event.currentTarget.dataset.key;
        if (this.sortKey !== key) {
            this.sortKey = key;
            this.sortDir = 1;
        } else if (this.sortDir === 1) {
            this.sortDir = -1;
        } else {
            this.sortKey = null;
            this.sortDir = 1;
        }
    }

    tipEnter(event) {
        const id = event.currentTarget.dataset.id;
        const u = this.data.units.find((x) => x.unitId === id);
        if (!u || u.nnnMonthlyTotal == null) return;
        const r = event.currentTarget.getBoundingClientRect();
        this.tip = {
            style: 'left:' + Math.round(r.right) + 'px; top:' + Math.round(r.top - 8) + 'px',
            suite: 'Suite ' + (u.suite || '—'),
            tax: u.nnnTax == null ? '—' : money(u.nnnTax),
            ins: u.nnnInsurance == null ? '—' : money(u.nnnInsurance),
            cam: u.nnnCam == null ? '—' : money(u.nnnCam),
            total: money(u.nnnMonthlyTotal),
            psf: u.nnnPsf == null ? '—' : psf(u.nnnPsf)
        };
    }

    tipLeave() {
        this.tip = null;
    }
}
```

Behavior notes baked into the code above (do not "simplify" them away):
- Sorting is three-state (asc → desc → off) and nulls/vacants always sort last regardless of direction — `Infinity` short-circuits before the `sortDir` multiplier.
- A row expands only when occupied; the expanded map is keyed by record Id so sorting doesn't collapse rows.
- Expiry dot thresholds: `> 12` months green, `>= 6` amber, else red — computed against today's date with a 30.44-day month.
- A step is "Active now" only when BOTH period dates exist and today is within them; label-only steps (`periodLabel` set) can never be active.
- Null step rent renders the `note` (italic) instead of a price — the design's "3% annual bumps" rows.
